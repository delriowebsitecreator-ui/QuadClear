QuadClear Service Website

Files included:
- index.html
- styles.css
- script.js

How to use:
1. Open index.html in your browser to preview the website.
2. Replace the placeholder phone number, email, and service area.
3. Upload the files to a hosting platform like GoDaddy, Wix custom code area, Netlify, Vercel, or your web developer's hosting.

Important:
The quote form is only a design right now. It needs to be connected to email, SMS, or a form service before it can receive customer requests.
